## Using the data

You may share and adapt the data, including for commercial use, as long as you:

- **Credit it** to the Stephen King API and the sources above, with a link to this license.
- **Share alike:** if you publish a modified version of the data, it must be under CC BY-SA 4.0 or a compatible license.

Using the API in an app doesn't make the app itself subject to CC BY-SA. Only redistributed or modified data is.
